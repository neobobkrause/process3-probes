<section id="mechanics"><h2>3. What loads, stays, disappears and returns</h2>
<h3>Separate the layers</h3>
<ol><li><strong>Durable source:</strong> repository files and canonical pages can persist without being present in the active model input.</li>
<li><strong>Instruction discovery:</strong> the harness selects and assembles instructions, with its own precedence, trust, byte limits and caching.</li>
<li><strong>Tool delivery:</strong> reading a file produces a bounded tool response; commands may succeed while responses omit content.</li>
<li><strong>Active context:</strong> only supplied input is available for the current inference. A stored transcript is not proof all its contents remain active.</li>
<li><strong>Compaction or replacement:</strong> the harness can construct a new active history, sometimes with summaries or retained items. That does not prove exact restoration of every canon clause.</li></ol>
