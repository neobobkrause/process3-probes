Run the actual HTTP app in the existing OpenAI-managed execution environment, bound only to 127.0.0.1. No paid provisioning, public hosting, account, credential, or arbitrary network is needed. An external walk means exercising HTTP from a client separate from app internals on this development service, not calling handler methods. A browser or an independent standard-library urllib client is suitable; capture actual URL/status/body observations. Record the tested integration SHA, provider revision, service command and time. Never describe a planned walk as performed.

1. Open http://127.0.0.1:8765/. Confirm Workshop card quote, Quantity label, visible unit price and allowed range. Enter 12 and submit. Initial result must show 12 cards and $30.00. Use Start again and confirm initial form.
2. Request /quote?quantity=0, /quote?quantity=abc and /quote with no parameter. Each must return 400 with actionable current bounds, usable form and no quote total. Request /missing; expect readable 404 with home link.
3. After provider revision is integrated, restart the service from that exact integration head. Confirm unit price $2.75, range 1–50, 12 costs $33.00, 50 costs $137.50, and 51 produces 400 mentioning 1 to 50. Confirm provider notices exist for both web and declared-but-unassigned report; notice inspection is an integration control, not a fourth product test.
4. For the interrupted web correction, first record the unfinished rejected-input behavior, then after replacement integration request /quote?quantity=abc. Confirm 400, entered abc retained for editing and no total. Request a percent-encoded HTML tag (e.g. quantity=%3Cscript%3E); confirm escaped text in input and no executable markup. Submit a valid 2 afterwards; expect $5.50 and no stale error.
